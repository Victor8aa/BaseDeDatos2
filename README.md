BaseDeDatos2

Creador: Victor (@Victor8aa)

Descripción
Generador de registros ficticios de alumnos para un sistema escolar, con opciones para exportar los datos en formatos SQL, CSV y JSON.

Tecnologías
- HTML
- CSS
- JavaScript
- SQL

Funcionalidades
- Generar nombres, apellidos, matrículas y correos de alumnos.
- Elegir la cantidad de registros.
- Generar archivos SQL, CSV y JSON.
- Descargar los datos generados.
